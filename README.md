# KANKA Beta 16 — ruhiges Design

Diese Version reduziert Farbverläufe, Glanzeffekte und bunte Kacheln. Die Oberfläche nutzt Cremeweiß, Anthrazit und ein dezentes Weinrot. Das Logo ist ein schlichtes Symbol aus türkischem Teeglas und Haus.

## Dateien
- `index.html` — App-Oberfläche
- `manifest.webmanifest` — PWA-Metadaten
- `assets/` — Logo- und Home-Bildschirm-Icons

Alle Dateien und den gesamten Ordner `assets` gemeinsam in das GitHub-Pages-Verzeichnis hochladen.
