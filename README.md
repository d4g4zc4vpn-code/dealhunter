## Installation auf GitHub Pages
1. Alle Dateien und den Ordner `assets` aus `DealHunter` ins veröffentlichte Verzeichnis deines GitHub-Pages-Repositories übernehmen.
2. Die Ordnerstruktur beibehalten: `index.html`, `manifest.webmanifest`, `assets/kanka-icon.png`, `assets/kanka-180.png`, `assets/kanka-favicon.png`.
3. Committen und warten, bis GitHub Pages die Änderungen veröffentlicht hat.
4. Auf dem iPhone in Safari die veröffentlichte Webseite öffnen, Teilen antippen und „Zum Home-Bildschirm“ wählen. Falls das alte Symbol bleibt, den alten Home-Bildschirm-Link entfernen, Safari neu laden und erneut hinzufügen.

## Hinweis
Das Manifest und die Icons richten die PWA-Metadaten ein. GitHub Pages unterstützt HTTPS, das für die Installation als Web-App benötigt wird. Die tatsächliche Darstellung des Symbols kann je nach iOS-Version variieren.
